# Generador de Código Intermedio - JDK 23 + JavaFX
Proyecto Maven para IntelliJ IDEA.

Incluye todo el temario:
2. Generación de código intermedio
2.1 Prefija, Infija y Postfija
2.2 Notación Polaca, Código P, Triplos y Cuádruplos
2.3 Variables/constantes, expresiones, asignación, control, funciones y estructuras.

El menú superior concentra todos los temas. `main-view.fxml` está separado y es editable con Scene Builder.

Abrir en IntelliJ, seleccionar JDK 23 y ejecutar MainApplication o `mvn clean javafx:run`.
